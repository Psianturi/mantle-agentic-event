## 🤝 Contributing to Documentation

### When to Update Docs

- 🆕 Adding new features → Update PRD.md and relevant technical docs
- 🐛 Fixing bugs → Update LATEST_IMPROVEMENTS.md
- 🏗️ Architectural changes → Update ARCHITECTURE_RESTRUCTURE.md
- 🔒 Security updates → Update SECURITY.md
- 📦 Dependency updates → Update DEPENDENCY_UPDATE_GUIDE.md
- ⚙️ Configuration changes → Update .env.example

### Documentation Checklist

When updating documentation:

- [ ] Update date at top of document
- [ ] Verify all links work
- [ ] Check code examples compile/run
- [ ] Update INDEX.md if adding new document
- [ ] Update README.md if user-facing change
- [ ] Use clear, concise language
- [ ] Include diagrams/screenshots where helpful
